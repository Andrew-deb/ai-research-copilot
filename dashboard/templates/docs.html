Architecture

Browser
  └─ Flask on Render — dashboard, search, RAG, library
       ├─ Databricks Lakebase (Postgres 17 + pgvector)
       └─ MCP server on Databricks — research tools for the assistant

The browser talks only to Flask. Databricks credentials stay server-side; no token for it ever reaches a page.

Discovery

Papers come from OpenAlex, filtered to the configured research fields. Discovery sits behind a single function so other providers — arXiv, PubMed Central — can be added without changing anything downstream.

A topic is seeded by relevance the first time it is seen, then queried by publication date from a per-topic watermark, so a scheduled run returns what is new rather than what is most famous.

Relevance filtering

Two filters, because they catch different failures. A field filter removes other disciplines; an embedding gate scores each candidate against the topic and drops weak matches. The field filter alone lets through a chemistry database that happens to be labelled Computer Science; the gate alone lets through a bioinformatics paper that outranks real matches.

Full text and sections

Where an open-access copy exists, Conclusion, Discussion and Methods are extracted and indexed alongside the abstract. Repository copies (arXiv, PubMed Central, institutional archives) are tried before publisher copies, because repositories are deposited to be fetched.

Every outcome is recorded — ok, no_url, access_denied, not_found, not_pdf, parse_failed, no_sections — split by whether retrying could ever help.

Embeddings

nomic-ai/modernbert-embed-base, 768 dimensions, unit normalised, asymmetric: documents are encoded with search_document: and queries with search_query:. A wrong prefix produces a perfectly valid vector in the wrong neighbourhood, so the contract is validated before anything is written.

Retrieval

Cosine distance over pgvector with an HNSW index. Results arrive per chunk and are folded to one row per paper, keeping the best-matching passage as the displayed snippet — which is why a result can be labelled with the section it came from.

Quotas

Per-visitor limits shape usage; a global daily ceiling protects capacity. They are separate on purpose: clearing cookies resets the first and cannot touch the second. Each capability is metered independently, because a semantic search and an agent run differ by more than an order of magnitude in cost.

Privacy

Google sign-in provides name, email and profile picture. No Google token is kept after login. Collections, notes and reading progress are private to the account; the paper corpus is shared. Anonymous sessions persist nothing.
